A beautiful and interactive **Calendar Application** built using **HTML, CSS, and JavaScript**, featuring:
- Animated month transitions
- A **Dark/Light mode toggle**
- Dynamic year input with validation
- And a stunning **falling petals animation** for visual charm 🌸

This project blends elegant design with smooth animations, making it perfect for showcasing front-end development and UI/UX design skills.

---

## 🌟 Features

- 📅 **Fully functional monthly calendar**
- 🌙 **Dark/Light mode toggle** for theme switching
- ✨ **Falling flower animation** for added visual appeal
- 🔄 **Smooth month transition animations**
- ⌨️ **Editable year input** with validation and auto-formatting
- 🌈 **Gradient background** that adapts to the current theme
- 🎨 **Modern glassmorphism design** using backdrop blur

## 🧩 Customization
You can easily personalize this calendar:

🗓️ Start Month or Year: Change the default value of currentMonth or currentYear in the JavaScript section.

🎨 Colors and Gradients: Modify the background gradients in the body and .dark mode classes.

💐 Petal Animation Speed: Adjust the interval and duration inside createFlower() and the @keyframes fall animation.

🕹️ Animation Timing: Control animation smoothness by changing the delays in the .days div transitions.
